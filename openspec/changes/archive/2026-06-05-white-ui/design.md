## Context

Game Weaver 当前完全采用 Tailwind 内联深色类名（`bg-[#0b0d10]`、`text-zinc-100`、`border-zinc-800` 等），同时 `globals.css` 中包含 `prefers-color-scheme: dark` 媒体查询。本次改造的目标是将整个界面切换为白色/浅色主题，同时保持现有的布局和信息层级不变。

## Goals / Non-Goals

**Goals:**
- 所有界面区块从深色切换为白色/浅灰系
- 文字颜色从浅色切换为深色系，确保可读性
- 边框、分割线颜色切换为浅中性色
- 移除 dark mode 媒体查询，强制浅色模式
- 等待小游戏 canvas 背景同步切换为浅色
- 品牌色按钮（indigo、emerald、amber）在浅色背景上保持视觉辨识度

**Non-Goals:**
- 不改变页面布局和功能
- 不引入主题切换机制（不保留 dark mode 选项）
- 不修改非 UI 部分的业务逻辑（API 路由、AI 调用等）

## Decisions

### 1. 使用 CSS 变量 + Tailwind 语义色，而非全局替换 class

**选择**: 继续使用 Tailwind 内联类名，直接逐处替换颜色值。

**原因**: 当前项目约 200+ 处 Tailwind 颜色类名分散在 JSX 中，引入 CSS 变量抽象层需要重构所有引用，工作量相当，但引入了额外的间接层。直接替换更简单直接，与项目现有风格一致。

**替代方案**: 使用 CSS 变量 `--color-bg-primary` 等统一管理，一次性切换。不选的原因是现有代码没有这层抽象，强行引入反而增加理解成本。

### 2. 浅色调色板选择 Tailwind zinc 系

**选择**: 使用 Tailwind 内置 `zinc` 色阶（`zinc-50` ~ `zinc-900`）和 `white` 作为浅色主题的颜色体系。

**原因**: zinc 是中性灰色调，不会偏蓝或偏暖，与白色搭配呈现干净的现代风格。Tailwind 原生支持，无需自定义色值。项目中已经使用了 zinc 系列（只不过在深色主题中是 `zinc-100` 作为文字色），切换方向即可。

**替代方案**: 使用 `gray` 或 `slate` 色系。zinc 比 gray 更有质感，比 slate 更中性。slate 偏蓝，在白色界面中会有冷感。

### 3. 移除 `prefers-color-scheme: dark` 媒体查询

**选择**: 从 `globals.css` 中删除 `@media (prefers-color-scheme: dark)` 块。

**原因**: 用户要求"白色界面"，不保留自动跟随系统的暗色能力。删除后所有环境下都显示浅色。

### 4. Canvas 小游戏背景色切换

**选择**: 将等待小游戏的 canvas 背景从 `#111827`（zinc-900）切换为 `#f8fafc`（slate-50），文字色同步反转。

**原因**: canvas 内部使用 `fillStyle` 直接设置颜色，需要单独处理，不经过 Tailwind。

## Risks / Trade-offs

- **深色习惯用户不适应**: 对于喜欢暗色模式的用户，强制切换到亮色可能引起不适 → 无需缓解，这是用户明确提出的需求
- **对比度不足**: 某些浅色组合可能对比度不够，尤其是在低亮度屏幕上 → 实施后需目视检查所有区块，确保文字与背景有足够反差
- **品牌色可读性**: 彩色按钮上的文字（如 indigo-500 按钮上的白色文字）已经足够醒目，浅色背景下也问题不大
