## Why

当前 Game Weaver 页面采用上下堆叠布局：上方是创意输入与策划编辑区，下方是游戏预览区。用户必须滚动页面才能看到游戏预览，无法在编辑策划内容的同时实时观察生成结果。这严重影响了工具的可用性——用户的核心诉求是"边操作边看效果"，而当前布局割裂了操作与反馈的视觉连续性。参考 Bolt.new、v0.dev、Replit 等主流 AI 工具，它们均采用左右分栏布局，让操作区和预览区始终在同一视口中可见。

## What Changes

- 页面主体布局从上下堆叠改为左右分栏，操作区（输入+策划）在左，预览区在右，两者始终在同一视口内可见
- 左侧面板内部可纵向滚动，右侧预览区固定高度（撑满视口），不随左侧滚动
- 微调输入栏从预览区底部移至左侧操作区底部，与生成按钮就近放置
- 策划六个板块的卡片与编辑器整合为更紧凑的交互方式，减少垂直空间占用
- 等待小游戏（mini-game）和生成阶段进度条适配新的左右布局
- 全局视觉去 AI 化：去掉过度圆角、重阴影、大号 emoji、渐变卡片、脉冲动画等 AI 生成痕迹，改为克制专业的视觉风格
- 保持现有的亮色主题（light-theme 规范）不变

## Capabilities

### New Capabilities

- `side-by-side-layout`: 页面采用左右分栏布局，左侧为操作面板（创意输入、策划编辑、微调控制），右侧为游戏预览面板。两个面板始终同时可见，无需滚动。左侧面板内部可纵向滚动，右侧预览区高度固定为视口高度减去顶部导航栏。

## Impact

- `app/page.tsx` — 主要改动：重构 JSX 布局结构，将 grid-rows 改为 grid-cols 分栏
- `app/globals.css` — 可能需要微调全局样式或 CSS 变量
- `app/api/*` — 无需修改，后端 API 不受影响
- `lib/*` — 无需修改，业务逻辑不受影响
- `prompts/*` — 无需修改
